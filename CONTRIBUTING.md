# Contributing

This repository is designed to grow alongside a Data Structures & Algorithms course.

## Good next contributions

- Add one prerequisite lab at a time.
- Write tests before changing algorithm behavior.
- Keep visualizations beginner-friendly.
- Document the time and space complexity of every new algorithm.
- Include edge cases in each pull request.

## Commit style

Examples:

```text
feat: add sliding window visualizer
test: add recursion boundary cases
docs: explain dict average-case lookup
fix: validate empty two-pointer input
```
