# Blackjack Game

A simple, designable, and functional Blackjack game with card images and GUI.

## Project Structure

```
blackjack_game/
├── assets/
│   └── cards/
│       ├── 2_of_clubs.png
│       ├── 3_of_clubs.png
│       ├── ... (all 52 cards)
│       ├── generate_cards.py  # Script to regenerate card images
│       └── card_back.png
└── src/
    ├── __init__.py
    ├── card.py       # Card class
    ├── deck.py       # Deck class
    ├── hand.py       # Hand class
    ├── game.py       # Main game logic
    ├── gui.py        # Graphical user interface
    └── main.py       # Entry point
```

## Features

- **Full Blackjack Rules**: 
  - Dealer stands on 17 or higher
  - Blackjack pays 3:2
  - Ace is worth 1 or 11
  - Double down allowed

- **Graphical Interface**:
  - Tkinter-based GUI
  - Card images displayed for all cards
  - Dealer's first card hidden until stand
  - Score display
  - Chip tracking
  - Bet controls

- **Game Actions**:
  - Hit: Take another card
  - Stand: End your turn
  - Double Down: Double your bet and take one more card
  - New Game: Start a new round

## How to Run

### Prerequisites
- Python 3.6+
- Required packages: `Pillow` (for image handling)

Install dependencies:
```bash
pip install Pillow
```

### Running the Game
```bash
# From the project root
cd blackjack_game/src
python main.py
```

Or from anywhere:
```bash
python /path/to/blackjack_game/src/main.py
```

## Card Images

The game includes placeholder card images generated by `generate_cards.py`. 
You can replace these with your own custom card images by:

1. Place your images in `blackjack_game/assets/cards/`
2. Name them following the pattern: `{rank}_of_{suit}.png`
3. Supported ranks: `2, 3, 4, 5, 6, 7, 8, 9, 10, jack, queen, king, ace`
4. Supported suits: `hearts, diamonds, clubs, spades`

To regenerate placeholder images:
```bash
cd blackjack_game/assets/cards
python generate_cards.py
```

## Game Rules

- Standard 52-card deck
- Player starts with $1000 chips
- Dealer hits on 16 or less, stands on 17 or more
- Blackjack (Ace + 10-value card) pays 3:2
- Player can double down on first two cards
- Ace is worth 1 or 11 (whichever is better for the hand)

## Customization

You can customize the game by modifying:

- **Card appearance**: Replace images in `assets/cards/`
- **Game rules**: Edit `game.py` (e.g., change dealer stand rule)
- **UI theme**: Modify colors in `gui.py`
- **Number of decks**: Change `num_decks` parameter in `BlackjackGame` constructor

## Class Documentation

### Card
Represents a playing card with suit, rank, value, and image path.

### Deck
Manages a deck of 52 cards with shuffling and dealing functionality.

### Hand
Manages a hand of cards and calculates the score (handling Ace as 1 or 11).

### BlackjackGame
Main game logic including:
- Starting new games
- Player actions (hit, stand, double down)
- Dealer AI
- Win/loss detection
- Chip management

### BlackjackGUI
Graphical user interface with:
- Card display
- Score tracking
- Action buttons
- Bet controls
- Result display
