# Blackjack Game

A simple, designable, and functional Blackjack game with card images.

## Project Structure

- `assets/cards/` - Place your card images here (e.g., `ace_of_spades.png`, `king_of_hearts.png`)
- `src/` - Source code for the game

## Card Images

You can use standard playing card images. Recommended naming convention:
- `2_of_clubs.png`, `3_of_clubs.png`, ..., `10_of_clubs.png`, `jack_of_clubs.png`, `queen_of_clubs.png`, `king_of_clubs.png`, `ace_of_clubs.png`
- Repeat for diamonds, hearts, spades

## Game Features to Implement

1. Card deck with 52 cards
2. Shuffling functionality
3. Dealing cards to player and dealer
4. Score calculation (Ace = 1 or 11, face cards = 10)
5. Hit/Stand functionality
6. Win/Lose/Push detection
7. Card image display
