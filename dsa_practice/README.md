# DSA Practice Projects

This folder contains starter projects for practicing Data Structures and Algorithms in Python and C++.

## Structure

- `python/` - Python algorithm implementations
- `cpp/` - C++ algorithm implementations

## How to Use

1. Navigate to the language folder of your choice
2. Create new files for each algorithm you want to implement
3. Follow the template provided in each language's README
4. Test your implementations
